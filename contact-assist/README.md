# お問い合わせ入力支援アプリ（ローカル）

企業ごとに、**調べて・判断して・入力用の文字列を用意する**ところまでをアプリが行い、
**フォームへの貼り付け・reCAPTCHA・確認／送信は、必ず人間が行う**ためのパソコン用アプリです。

あなたの操作は、ほぼこれだけになります。

```
コピー → Ctrl+V → コピー → Ctrl+V → … → reCAPTCHA → 目で確認 → 送信（人間）
```

---

## このアプリがやること／やらないこと

| やること（アプリ） | やらないこと（アプリは絶対にしない） |
|---|---|
| Excelを読み、企業・文面・送信者情報を自動で見つける | **Excelへの書き込み・変更**（元のExcelは1バイトも変えません） |
| 公式サイトを探し、問い合わせフォームを見つける | **フォームへの入力・貼り付け・選択・チェック** |
| 営業禁止（セールスお断り）の記載を探す | **reCAPTCHA等の認証の操作** |
| 採用職種を調べ、Excelの文面の中から合うものを選ぶ | **確認ボタン・送信ボタンを押すこと** |
| フォームの入力欄・必須／任意・入力条件を読み取る | 営業禁止サイトへ送るよう案内すること |
| 欄ごとに「そのまま貼れる文字列」を作り、コピーボタンを付ける | アクセス制限・bot対策の回避 |
| Excelへ転記する内容（判定・職種・文面番号・memo）も用意する | 文面の要約・言い換え・誤字修正（Excelの文章は一字も変えません） |

不確かなときは**推測せず「要確認」と表示して止まります**。

---

## 準備（最初の1回だけ）

1. **Google Chrome**（または Microsoft Edge）が入っていること。
2. **Node.js**（無料）をインストールします。
   - https://nodejs.org/ja から「LTS」（推奨版）をダウンロードして、そのまま「次へ」で進めてください。
3. （任意）**Claude Code**がパソコンにあって、ログイン済みなら、AI判断が使えます。
   なくても動きます（その場合、判断が必要な所は「要確認」になります）。

## 起動のしかた

1. このフォルダ（`contact-assist`）の中の **`start.bat` をダブルクリック**します。
   - 最初の1回は、部品のダウンロードで数分かかります（黒い画面に文字が流れます。閉じないでください）。
2. しばらくすると、**ブラウザにアプリの画面が自動で開きます**。
   - 開かなかったら、ブラウザで `http://127.0.0.1:4823/` を開いてください。
3. 終わるときは、**黒い画面を閉じる**（または `Ctrl+C`）だけです。
   作業の途中経過は自動で保存されるので、次回は続きから再開できます。

> Mac / Linux の場合は `start.sh` を実行します。

## Excelの読み込ませ方

1. アプリの最初の画面で **「Excelファイルを選ぶ…」** を押して、Excelを選びます。
   - または、入力欄に**ファイルの場所**を貼り付けて「読み込む」。
     エクスプローラーでファイルを `Shift + 右クリック` →「パスのコピー」で、そのまま貼れます（`"` が付いていてもOK）。
2. 読み込むと、アプリが**Excelの中身を見て、どれが「企業一覧」「問い合わせ情報」「文面」かを自動で判断**します。
   - シートの名前・順番、列の位置、見出しが1行目にあるか、は問いません。
   - Excelは **`.xlsx` / `.xlsm`** に対応しています（古い `.xls` は、Excelで「名前を付けて保存」から `.xlsx` にしてください）。
3. 判断できたら企業一覧が表示されます。判断できなかったら →「Excel構造確認が必要」（後述）。

### アプリが期待するExcelの内容（目安）

シート名・列の順番は自由です。次のような**意味のある見出し**があれば自動で見つけます。

| 役割 | 見つける手がかり（別名にも対応） |
|---|---|
| 企業一覧 | 見出しに「企業名／会社名／法人名／事業者名」など。あれば「企業HP／URL／公式サイト」「業界」「職種」「memo」「文面番号」「判定」も認識 |
| 文面一覧 | 見出しに「本文／お問い合わせ内容／メッセージ」＋「職種」。あれば「No／文面番号」「件名／タイトル」「想定ターゲット」「採用単価」も認識 |
| 問い合わせ情報（送信者） | 「会社名／部署／役職／氏名／姓／名／フリガナ／メール／電話番号／郵便番号／住所…」といった**項目名と値**が並んでいる表（縦並びでも横並びでもOK）。項目名の右に**分割した値**（姓｜名、電話 080｜1234｜5678、住所の都道府県｜市区町村｜番地｜建物 など）が並んでいても、値の種類を見て読み分けます。全体の値と分割値が食い違うときは「マスターデータ矛盾」になります |

## 通常の作業手順

1. **左の一覧から企業を選び、「調査する」** を押します。
   - 「ここから順に連続調査」を押すと、選んだ企業から順に自動で調査します（1社失敗しても次へ進みます）。
   - 調査中は、**調査用のChromeが自動で開いて、ページを見て回ります**（入力や送信は一切しません）。
2. 結果を見ます（画面の上のほうに、まず**判定**が出ます）。

   - **〇** … 使えます。そのまま3へ。
   - それ以外（営業お断り、フォーム無し、…）… 赤や黄色の枠に**理由・確認URL・根拠**が出ます。**指示に従ってください**。
3. **Excelへ転記する内容**（画面の「Excel転記用」）の **[コピー]** を押して、Excelの該当セルに自分で貼り付けます。
   （判定／職種／文面番号／memo。アプリはExcelに書き込みません）
4. **「フォームを開く（調査用Chrome）」** を押して、問い合わせフォームを開きます。
   - 並べて表示しておくと便利です（アプリの画面とフォームの画面を左右に）。
   - reCAPTCHAが厳しい場合は「既定のブラウザで開く」を使ってもOKです。
5. 画面右の **「フォーム入力」** は、**フォームと同じ順番**で並んでいます。上から順に
   **[コピー] → フォームの欄をクリックして `Ctrl+V`** を繰り返します。
   - 押したボタンは **「✓ コピー済み」** になります（何度でも押し直せます）。
   - **【必須】【任意】** の表示があります。
   - 「項目なし：役職」のように出る欄は、Excelにデータがないので空のままにします（勝手に作りません）。
   - 「`「東京都」を選択`」のような表示は、**コピーではなく、あなたが選ぶ**欄です。
   - **本文**は長いので、「本文をコピー」ボタンがスクロールしても見える位置に付いています。
     本文は「**対象企業名 + 改行 + Excelの本文そのまま**」です。文字数と上限も表示されます。
6. **reCAPTCHA** があるときは「あり」と表示されます。人間が操作します。
7. 内容を**目で確認**して、**確認／送信ボタンを人間が押します**。
8. 「確認画面」へ進むタイプのフォームで、画面の読み直しが必要なときは「**現在ページを再解析**」を押します
   （アプリが画面を進めることはありません）。
9. **「次の企業 ▶」** へ。コピー済みの表示は企業を変えるとリセットされます。

## 画面に出るステータスの見かた

| 表示 | 意味 | どうする |
|---|---|---|
| **〇** | 使えます | 作業を進める |
| **営業お断り** | サイトに「営業目的の問い合わせは禁止」の記載があった | **この企業には送らない。** 根拠の文とURLが出ます。Excelには「営業お断り」と転記 |
| **営業可否要確認** | 営業禁止かどうか判断しきれない | 根拠のページを開いて自分で判断。送ってよければ「確認した（営業可として進める）」 |
| **フォーム無し** | 公式サイトを探しても問い合わせフォームがない | 送らない（メールだけの場合は理由に表示） |
| **対象外フォーム** | 患者専用・応募者専用・会員専用など、営業先として不適切 | 送らない |
| **企業特定要確認** | 同名の別企業の可能性などで、公式サイトを一つに決められない | Excelに企業URLを入れて「Excelを再読込」→ 再調査 |
| **アクセス不可** | サイトが開けない／アクセス制限がある | 時間をおいて再調査（制限の回避はしません） |
| **文字数制限** | 本文がフォームの上限より長い | 送らない or 別の文面を選ぶ（**アプリは文章を短くしません**） |
| **入力必須データ不足** | フォームの必須欄に対応するデータがExcelにない | Excelの「問い合わせ情報」に追記して再読込 |
| **マスターデータ矛盾** | 問い合わせ情報で、同じ意味の値が食い違っている | 画面の候補から正しいほうを選ぶ（後述） |
| **フォーム解析要確認** | 必須の入力欄の意味が分からない／特定の人向けか不明 | フォームを見て、自分で入力 |
| **住所分割要確認 / 電話番号分割要確認 / 氏名分割要確認** | 住所・電話・氏名の「区切り」を確実に決められない | 該当欄だけ自分で入力。Excelに区切った値を用意すると解決します |
| **職種選定要確認** | 採用職種を決められなかった | 画面の「職種」から選ぶ（Excelの文面にある職種だけが出ます） |
| **その他エラー** | 上記以外 | メッセージを確認 |

「**近似職種**」と出た場合は、ぴったりの職種がなかったので、Excelの職種の中で一番近いものを選んだという意味です（理由は「調査の根拠」で確認できます）。

## Excelを変更したとき

Excelを編集して保存したら、アプリ上部の **「Excelを再読込」** を押すだけです（アプリは起動したままでOK）。

- 企業の追加・削除・並べ替え、列の追加・削除・移動、列名やシート名の変更、
  職種や文面の追加・削除・番号の変更、件名・本文の変更、送信者情報の変更 …
  これらは**コード修正なしでそのまま反映**されます。
- 何が変わったかは、画面の上に **「Excelの変更を検出しました」** として表示されます。
- **本文・件名・送信者情報は、常に「いま読み込んだExcel」の内容**が使われます。アプリが古い内容を覚えていて使うことはありません。
- 企業のURLを変えた企業は、古い調査結果を捨てて「未調査」に戻ります。

---

## 「Excel構造確認が必要」と出たとき

Excelの中身から**企業一覧・文面・問い合わせ情報の場所を安全に決められない**ときは、推測で進まずこの画面になります。

1. 画面のシート一覧で、アプリがどう判断したかを確認します。
2. 足りない部分（「企業一覧」「文面一覧」「問い合わせ情報」）の枠で、
   - **シート**を選ぶ
   - **見出しの行**を選ぶ（黄色くハイライトされます）
   - 「企業名に使う列」「本文に使う列」…を選ぶ
   - 「この設定で読み込む」を押す
3. 一度決めた設定は**このパソコンに保存**されます（Excelは変更しません）。
   次回以降は、**Excelの見出しと照らし合わせて再検証**してから使います。Excelの構造が変わっていたら、保存設定は使わず自動判定をやり直し、決められなければまたこの画面になります。

**設定を最初からやり直したい**ときは、`data/settings.json` を削除する（または画面で選び直す）とリセットされます。

## マスターデータ矛盾が出たとき

送信者の情報（問い合わせ情報）に、**同じ意味なのに値が違うもの**があると、アプリはどちらも採用せず止まります。

```
電話番号の候補が一致しません
候補1: 080-1234-5678
候補2: 090-9999-0000
```

正しいほうの **[この値を使う]** を押してください。選択は**このパソコンにだけ保存**され、元のExcelは変えません。
（ハイフンの有無、全角・半角、スペースの違いだけなら「矛盾」とは扱いません。）
Excelの数値セルに電話番号が入っていて**先頭の「0」が欠けている**ときも、確認を求めます。

## 再調査のしかた

画面上のボタンで、やり直したい範囲を選べます。

| ボタン | 何をやり直すか |
|---|---|
| **現在企業を再調査** | 公式サイト探し〜営業禁止確認〜職種〜フォーム解析をすべてやり直す |
| **フォームを再解析** | フォームの入力欄だけ読み直す（フォームが更新されたとき） |
| **AI判定だけ再実行** | ページは取り直さず、AIの判断（営業可否・職種・不明な欄）だけやり直す |
| **現在ページを再解析** | 「調査用Chrome」で開いているページ（確認画面など）を読み直す |
| **Excelを再読込** | 企業一覧や文面を最新のExcelに更新する |

## AI機能とプライバシー

- AIは、**迷う判断だけ**（同名企業の見分け、採用職種の選択、営業禁止の言い回しの意味、特殊な入力欄の意味）に使います。
  文字数計算・変換・フォーム解析・コピーなどは、AIを使わない普通のプログラムです。
- AIには、**公開されているウェブページの文章・入力欄の名前・Excelの職種名の一覧**だけを送ります。
  **氏名・メール・電話・住所・本文は送りません。**
- 使うのは、パソコンにある **Claude Code**（`claude` コマンド）です。**APIキーは不要**です。
  使えない環境では自動で「AIなし」になり、迷う所は「要確認」になります。
- 画面上部の「AIオフ」を押すと、AIを使わない設定にできます。
- 外部の解析サービス・アクセス解析・外部データベースへの送信は一切ありません。

|---|---|

| `data/logs/` | 動作ログ（企業名・処理・成功/失敗・URL・日時など。氏名・メール・電話・住所・本文は残しません） |

## 困ったとき

| こんなとき | 対処 |
|---|---|
| `start.bat` を押しても黒い画面がすぐ消える | Node.js が入っていません。「準備」を実施してください |
| ブラウザが開かない | `http://127.0.0.1:4823/` を直接開く |
| 「ポート4823はすでに使われています」 | アプリが二重に起動しています。黒い画面を全部閉じてからやり直す |
| Excelが読み込めない | Excelで開いたまま保存していないか確認。`.xlsx` で保存し直す |
| 調査用Chromeが開かない | Google Chrome または Microsoft Edge をインストール |
| 画面が古い／おかしい | `dist-ui` フォルダを削除して `start.bat` をやり直す |
| Excelをどう読み取ったか確認したい | `npm run inspect -- "C:\\場所\\ファイル.xlsx"`（個人情報は伏せ字で表示。`--show-values` で表示） |
| 動作確認用のダミーExcelが欲しい | `npm run sample:excel`（`samples/sample.xlsx` ができます。架空のデータです） |

## 既知の制限

- 公式サイトの特定は、ExcelのURLを優先し、無い／開けないときだけ検索（DuckDuckGo → Bing）を使います。
  検索サイトが確認画面（CAPTCHA）を出したら、回避せずに中止して「企業特定要確認」にします。
  同名企業の見分けは、ページ内の企業名の一致とAI判断が中心で、所在地の突き合わせまでは行いません。
- 採用職種は、公式サイトの採用ページ・事業内容が中心です（外部の求人サイトまでは調べません）。
- 画像だけで作られたフォーム、独自のJavaScript部品（`<input>` を使わない疑似入力欄）は読み取れないことがあります。
  その場合は「フォーム解析要確認」になります。
- 住所の「市区町村」「番地」などを別欄に分ける場合、確実に分けられるのは**Excelに分割した値があるとき**と、
  **都道府県・東京23区**のみです。それ以外は「住所分割要確認」にします（境界を推測しません）。
- 電話番号の区切りは、**Excelにハイフン付きの値があるとき**と、携帯(070/080/090)・050・フリーダイヤル・03/06などの**確実な番号体系**のときだけ決めます。
- 1つのExcelシートに複数の表（企業一覧と文面など）が同居している構成には対応していません。

### 安全設計

- **ブラウザ操作層に入力コードが存在しません。** Playwright の `Page/Frame` は allowlist の Proxy で包まれ、
  `fill / type / press / check / selectOption / click / setInputFiles / locator / keyboard / mouse …` は呼んだ瞬間に例外になります（`src/browser/safe-page.ts`）。
